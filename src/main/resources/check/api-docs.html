REST API Documentation

This application provides REST APIs using DTOs and MapStruct mappers for clean data transfer.

Base URL

http://localhost:8081/api/v1

Authentication

Most endpoints require user session authentication. Login through the web interface first.

Health Check

GET /api/v1/health

Check if the API is running

curl -X GET http://localhost:8081/api/v1/health

Response:

"Ecommerce API is running!"

User APIs

GET /api/v1/users/profile

Get current user profile (requires authentication)

curl -X GET http://localhost:8081/api/v1/users/profile \ -H "Cookie: JSESSIONID=your-session-id"

Response:

{ "id": 1, "username": "john_doe", "email": "john@example.com", "phoneNumber": "1234567890" }
GET /api/v1/users/{id}

Get user by ID

curl -X GET http://localhost:8081/api/v1/users/1

Product APIs

GET /api/v1/products

Get all products

curl -X GET http://localhost:8081/api/v1/products

Response:

[ { "id": 1, "name": "Laptop", "description": "High-performance laptop", "price": 999.99, "stockQuantity": 10, "imageUrl": "laptop.jpg" } ]
GET /api/v1/products/{id}

Get product by ID

curl -X GET http://localhost:8081/api/v1/products/1
POST /api/v1/products

Create a new product

curl -X POST http://localhost:8081/api/v1/products \ -H "Content-Type: application/json" \ -d '{ "name": "New Product", "description": "Product description", "price": 29.99, "stockQuantity": 100, "imageUrl": "product.jpg" }'

Order APIs

GET /api/v1/orders

Get user orders (requires authentication)

curl -X GET http://localhost:8081/api/v1/orders \ -H "Cookie: JSESSIONID=your-session-id"

Response:

[ { "id": 1, "userId": 1, "username": "john_doe", "orderDate": "2024-01-15T10:30:00", "status": "PENDING", "subtotal": 99.99, "discountAmount": 10.00, "totalAmount": 89.99, "discountCode": "WELCOME10", "orderItems": [ { "id": 1, "productId": 1, "productName": "Laptop", "quantity": 1, "price": 99.99, "totalPrice": 99.99 } ] } ]
GET /api/v1/orders/{id}

Get order by ID (requires authentication)

curl -X GET http://localhost:8081/api/v1/orders/1 \ -H "Cookie: JSESSIONID=your-session-id"

Architecture Features

DTOs (Data Transfer Objects)
  • UserDto - User data without sensitive information
  • ProductDto - Product information
  • OrderDto - Order details with nested OrderItemDto
  • OrderItemDto - Individual order items
MapStruct Mappers
  • UserMapper - Maps User entity to/from UserDto
  • ProductMapper - Maps Product entity to/from ProductDto
  • OrderMapper - Maps Order entity to/from OrderDto
  • OrderItemMapper - Maps OrderItem entity to/from OrderItemDto
Security Features
  • Password fields are excluded from JSON responses using @JsonIgnore
  • Session-based authentication for protected endpoints
  • User authorization checks for order access
